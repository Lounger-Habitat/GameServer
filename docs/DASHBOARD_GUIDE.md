# 统计 Dashboard 使用指南

## 快速开始

### 1. 访问 Dashboard

在浏览器中打开：
```
http://localhost:8000/statistics/dashboard
```

### 2. 登录

输入您的 API Key（以 `sk-` 开头）并点击"登录"按钮。

**创建 API Key**：
```bash
# 创建管理员 Key
uv run utils/api_key.py create admin

# 创建普通用户 Key  
uv run utils/api_key.py create test-user
```

## 界面功能

### 🎨 设计特点

参考 **Google AI Studio** 的设计风格：
- **深色主题**：专业、舒适的视觉体验
- **现代化布局**：清晰的信息层级
- **响应式设计**：适配各种屏幕尺寸

### 📊 标签页

#### 1️⃣ 使用情况 (Usage)

**关键指标卡片**：
- **总 API 请求**：累计调用次数
- **成功请求**：成功率百分比
- **总 Token 使用**：累计 Token 消耗
- **流式请求**：流式调用占比

**时间序列图表**：
- **API 请求趋势**：每日请求次数折线图
- **Token 使用趋势**：每日 Token 消耗柱状图

**Keys 排行榜**（仅管理员）：
- 按使用量排序的 API Keys 列表
- 显示请求次数、Token 使用、流式请求数

#### 2️⃣ 费用统计 (Billing)

**费用指标卡片**：
- **总费用**：累计消费金额（元）
- **平均每次调用成本**：单次调用平均费用
- **输入 Token 费用**：输入部分的费用
- **输出 Token 费用**：输出部分的费用

**费用图表**：
- **费用趋势**：每日费用折线图
- **费用分布**：按模型的费用占比

**Keys 费用排行**（仅管理员）：
- 按费用排序的 API Keys 列表
- 显示总费用、请求次数、平均成本

## 权限说明

### 👤 普通用户
- 只能查看自己的统计数据
- 看到的是当前 API Key 的使用情况和费用

### 👑 管理员
判断标准：API Key 名称包含 `admin`（不区分大小写）

管理员额外权限：
- ✅ 查看所有 Keys 的总体统计
- ✅ 切换查看不同 Key 的数据
- ✅ 查看 Keys 使用排行榜
- ✅ 查看 Keys 费用排行榜

## 数据说明

### 统计维度

1. **API 调用统计**
   - 总调用次数
   - 成功/失败次数
   - 流式/非流式调用
   - 每日调用趋势

2. **Token 使用统计**
   - 输入 Token 数量
   - 输出 Token 数量
   - 总 Token 消耗
   - 每日 Token 趋势

3. **费用统计**
   - 根据模型定价自动计算
   - 区分输入/输出费用
   - 每日费用趋势
   - 按模型的费用分布

### 数据来源

所有数据由统计中间件自动记录：
- 实时捕获每次 API 调用
- 自动解析 Token 使用情况
- 根据模型定价计算费用
- 存储在 SQLite 数据库中

## 使用场景

### 场景 1：个人开发者

**目标**：监控自己的 API 使用情况

1. 使用普通用户 Key 登录
2. 查看"使用情况"标签
3. 关注 Token 消耗趋势
4. 切换到"费用统计"查看成本

### 场景 2：团队管理员

**目标**：管理多个 API Key 的使用

1. 使用管理员 Key 登录
2. 在"使用情况"标签查看总体数据
3. 使用 Key 选择器切换查看不同成员
4. 在排行榜中识别高使用量的 Key
5. 在"费用统计"中分析成本分布

### 场景 3：成本优化

**目标**：降低 API 调用成本

1. 查看"费用统计"标签
2. 分析费用趋势图，找出高峰期
3. 查看按模型的费用分布
4. 考虑切换到更经济的模型
5. 优化高成本的调用模式

## 常见问题

### Q: 为什么看不到数据？
A: 可能原因：
1. 还没有 API 调用记录
2. 选择的时间范围内没有数据
3. 数据库文件不存在或损坏

解决方法：
- 先发送几次测试请求
- 选择"全部时间"查看
- 检查 `statistics.db` 文件

### Q: 管理员看不到其他 Key 的数据？
A: 检查：
1. API Key 名称是否包含 `admin`
2. 是否已创建其他 API Key
3. 其他 Key 是否有调用记录

### Q: 图表显示不正确？
A: 尝试：
1. 刷新页面
2. 清除浏览器缓存
3. 检查浏览器控制台错误

### Q: 费用计算准确吗？
A: 费用计算基于：
- `api/menglong/config.py` 中的模型定价
- 实际的 Token 使用量
- 自动区分输入/输出 Token

如需调整定价，请修改配置文件。
